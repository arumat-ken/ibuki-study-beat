# モックアップ置き場

GUI設計のHTMLモックアップを置くフォルダです。

| ファイル | 役割 |
|---|---|
| `_starter.html` | **モック作成用のスターター**。実アプリのデザイントークンと共通コンポーネントを収録済み。これを土台にすること |
| `v4.html` | **← ChatGPTの成果物②(HTMLモック)を置く場所** |

## スターターHTMLの見方

ブラウザで開くか、次のURLで直接見られます(公開リポジトリのため)。

```
https://arumat-ken.github.io/ibuki-study-beat/docs/mockups/_starter.html
```

収録済みのコンポーネント: カード / ボタン各種 / 進捗バー / チップ / 統計チップ /
トグル / 吹き出し / ステージ / 下部ナビ(6タブ) / ボトムシート型モーダル /
中央メッセージ / お祝い演出 / トースト / キャラ画像プレースホルダ

## モック作成のルール

1. **外部CDN・外部画像を読み込まない**(インラインCSS/SVGのみ)
2. **320px幅で崩れない**こと(iPhone SEを想定)
3. タップ領域は **44×44px以上**
4. 入力欄の `font-size` は **16px固定**(iOSの自動ズーム防止。変更不可)
5. キャラクター画像の位置には `<div class="char-ph"></div>` を置く
   (実画像 `assets/char/*.png` は実装時に差し込む)
6. **本番の実装ロジック(JavaScript)は書かない。** 画面切替など、モックの閲覧に
   必要な最小限のスクリプトのみ

## モックが置かれたあと

Claudeが `v4.html` をPlaywrightで実際にレンダリングし、
iPhone幅と320px幅の両方でスクリーンショットを撮って確認します。
文章だけのやり取りより認識のズレが出ないため、モックの提出を推奨しています。
