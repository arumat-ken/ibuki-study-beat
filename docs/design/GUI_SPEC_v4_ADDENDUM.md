## 2. H-2 集中モードの修正【元設計からの変更】

### 変更理由

元設計は集中モードで**コーチタブごと非表示**にしていたが、コーチ画面には
**既存 ver.3.3.0 の機能**が含まれている。

| コーチ画面の機能 | 種別 | 集中モードでの扱い |
|---|---|---|
| ポーズ変更 | 既存 | **残す** |
| メッセージ(端末内コーチ) | 既存 | **残す** |
| **🤖 AIに聞く** | 既存 | **必ず残す**(受験直前こそ小論文・面接の相談に必要) |
| 装備 | ver.4 新規 | 隠す |
| ショップ | ver.4 新規 | 隠す |
| 仲間コレクション | ver.4 新規 | 隠す |

親の当初要望は「**金融・ショップ機能**が自動でOFF」であり、コーチ画面全体の非表示ではなかった。

### 変更後の仕様

- 集中モード中のタブは **5タブ**(今日 / 記録 / グラフ / **コーチ** / 設定)
- 隠れるのは **世界タブ**と、コーチ内の **装備・ショップ・仲間** カードのみ
- 実装は CSS の `.phone.focus-mode .focus-hide { display: none; }` と、
  対象カードへの `focus-hide` クラス付与で行う(要素は削除しない)
- 案内文: 「隠れるのは世界タブ・装備・ショップ・仲間・金融です。**コーチは残ります**。
  小論文や面接の相談に『AIに聞く』を使えるようにするためです。」

## 3. B-1 海外ショップ【為替学習の中核】

### 設計

ショップモーダルの最上部に、カテゴリ(衣装/スキル/ステージ/消費)とは**別の切替**を置く。

```text
┌──────────────────────────┐
│ ビートショップ                  × │
│ 残高 12,450BP        装備は各1個  │
├──────────────────────────┤
│ [🇯🇵 国内ショップ] [🌍 海外ショップ] │ ← 追加
├──────────────────────────┤
│ (海外選択時のみ表示)              │
│ いまのレート 1 BD = 150円。        │
│ 円高(1BD=130円)になると、         │
│ 海外のほうが安く買えます。          │
├──────────────────────────┤
│ [衣装] [スキル] [ステージ] [消費]  │
├──────────────────────────┤
│ ✦ ライトアップジャケット   80 BD  │
│ 👟 LA限定スニーカー        30 BD  │ ← 海外限定
│ 🎩 フェドーラハット        20 BD  │
│    国内 3,000BP / 海外 20 BD      │ ← 同一商品を両方に置く
├──────────────────────────┤
│ 同じ帽子でも、円高(1BD=130円)なら  │
│ 海外は約2,600円で買えます。        │
│ 「いつ買うか」で得も損もします。    │
└──────────────────────────┘
```

### 設計上の要点

1. **同じアイテムを国内と海外の両方に置く**(例: フェドーラハット 国内3,000BP / 海外20BD)。
   これがないと「円高だと海外が安い」という体験が成立しない
2. **海外限定アイテム**(LA限定スニーカー等)を置き、「いつ買うか」を考えさせる
3. 海外タブを選んだときだけ**現在レートの注記を表示**する
4. 円換算額は参考表示にとどめ、購入は BD 建てで行う

## 5. C-1 ふるさとクエスト

### 設置場所

世界タブ、「週末のまとめ」と「金融ラボ」の間にカードを置く。

```text
│ ふるさとクエスト          2/5 › │
│ 地元と日本を知ることが、          │
│ 世界を語る土台になります。         │
```

### モーダル(furusato-modal)

| クエスト | 進捗表示 | ねらい |
|---|---|---|
| 📰 地元のニュースを10本 | 6/10 | 地域の課題・産業・行政を知る |
| 🏭 地元の企業を3社調べる | 3/3 ✓ | 面接で語れる地域経済の実感 |
| ⛩️ 地元の歴史スポットを訪ねる | 1/1 ✓ | 写真を1枚記録(散歩は運動ポイントにも) |
| 🏫 志望校のある街を歩く | 0/2 | 近畿大学・龍谷大学のキャンパス周辺 |
| 🎌 日本の伝統・文化を5つ調べる | 2/5 | 海外の人に日本を説明できるか |

- 全クエスト達成で **+1,500 BP** と仲間「ふるさとの応援団」を解放
- 導入文: 「自分の国を語れないと、他の国も理解できない。国際学部を目指すなら、まず足元から。」

### トーンの指針

**「知る」「関心を持つ」に軸足を置き、愛国心の押し付けにしない。**
愛着は教えられて生まれるものではなく、知った結果として自然に湧くものである。

## 7. C-3〜C-5 上限・制限の表示

経済が壊れないための安全装置。**画面に出ないと機能しない**ため、可視化する。

| 項目 | 値 | 表示場所 |

## 8. D-1 分割購入比較【必ず総額を並記】

購入確認モーダルに追加。**この画面を毎回見ること自体が教育**である。

```text
│ 支払い方法                        │
│ [一括] [3回] [6回] [12回]         │
├──────────────────────────┤
│ 支払い総額            59,000BP    │
│ 1回あたり        4,917BP × 12回   │
│ 一括との差           +9,000BP     │ ← 赤字で表示
├──────────────────────────┤
│ 分割にすると 9,000BP 多く払う      │
│ ことになります。                   │
├──────────────────────────┤
│ 信用スコア              620点 ›   │
│ きちんと返すと次から手数料が安くなる │
```

| 回数 | 総額 | 一括との差 |
|---:|---:|---:|
| 一括 | 50,000 BP | ±0 |
| 3回 | 52,500 BP | +2,500 BP |
| 6回 | 55,000 BP | +5,000 BP |
| 12回 | 59,000 BP | +9,000 BP |

**借金を推奨する設計にしない。** 一括が最も安いことを既定表示とし、
分割を選んだ瞬間に差額を赤字で提示する。

## 9. D-2 信用スコア詳細

金融ラボと購入確認の両方から開ける(credit-modal)。

```text
│ 現在のスコア  620点          標準 │
├──────────────────────────┤
│ これまで                          │
│ 初期値                    500点   │
│ 返済を完了 ×2            +100点   │
│ 完済 ×1                  +100点   │
│ 延滞 ×0                    −0点   │
├──────────────────────────┤
│ スコアでできること                 │
│ 700点以上      分割手数料が半額   │
│ 500〜699点     標準（いまここ）    │
│ 300点未満    分割払いが使えない   │
├──────────────────────────┤
│ 返済日に残高が足りないと −150点。  │
│ 信用は積み上げるのに時間がかかり、  │
│ 失うのは一瞬です。                 │
```

住宅ローンやクレジットカードの審査の縮図。**「信用は積み上げるもので、失うのは一瞬」**
という感覚を、実際の得失を通じて体感させる。

## 11. 実装時の申し送り

1. **計算ロジックを先に固める。** 金利・為替差損益・分割払いの残高は、
   間違えると利用者の信頼を失う。`js/calc.js` に純粋関数として実装し、
   単体テストで固めてから UI に接続する
2. **倍率は足し算、フィーバーは置換。** 掛け算にすると 3.0 × 10 = 30倍 で経済が壊れる
3. **GTはBPから買えない。** マイルストーン達成でのみ発行する。この分離が親の支出を守る
4. **PayPay月間上限は円建てで固定。** 為替が動いても親の支出は変わらない設計を崩さない
5. `js/manual.js`(AIに渡す操作マニュアル)も、実装に合わせて更新すること
