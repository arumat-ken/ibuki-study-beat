# 追加機能 確定設計 — ver. 4.x

親(arumat-ken)とClaudeの協議で**確定済み**の機能設計。GUI設計はこの内容を前提とする。
**この仕様を勝手に変更・追加しないこと。** 提案がある場合は「提案」として明確に分離すること。

## 全体の構造

```
【稼ぐ】学習・ニュース・生活習慣 ──→ BP（倍率が効く）
                                     │
        ┌────────────────────────────┼──────────────────┐
        ↓                            ↓                  ↓
   【貯める】円預金             【両替】BD         【使う】国内ショップ
    金利 年0.2%〜0.5%            外貨預金 年4.5%     価格は固定
    （52倍速で週次付利）          為替リスクあり           │
        │                            │                  ↓
        └────────────┬───────────────┘          【使う】海外ショップ
                     ↓                              円換算は為替で変動
              【学ぶ】金利 vs 為替

【成果】模試UP・週末まとめ・単元制覇 ──→ GT ──→ PayPay
                                          （為替で価値が変動。
                                            月間上限は円建てで固定）

【借りる】高額アイテムの分割払い ──→ 手数料 + 信用スコア
```

**設計の核心**: 倍率が効くのは BP(ゲーム内通貨)だけ。GT(現実のお金の引換券)は
倍率の影響を受けず、マイルストーンでのみ発行される。この分離により、
どれだけ倍率を積み上げても親の支出は増えない。

## A. ポイント(BP)

### 基礎レート
- **学習1分 = 1 BP**
- **1日の獲得上限 1,500 BP**(倍率込みの最終値)
- 目安: 1日3時間=180BP / 1週間≒1,300BP / 1ヶ月≒5,500BP

### 行動ボーナス(倍率とは別枠の固定加算)

| 行動 | BP | ねらい |
|---|---|---|
| 計画達成(達成率80〜120%) | +50 | **時間を水増しすると達成率が崩れるので抑止になる** |
| 振り返りを書いた | +10 | 記録の質 |
| 3日連続 / 7日連続 / 30日連続 | +30 / +100 / +500 | 継続の山場 |
| 1日で全受験科目に触れた | +80 | 苦手科目の放置防止 |
| 単元クリア | +200 | 量ではなく質 |
| 模試を受けた / 前回より点数UP | +300 / +500 | 外部で検証できる成果 |

### 受験科目の任意選択
- 科目ごとに **「受験科目」チェック**を設定できる(私立大の科目に合わせて本人が選ぶ)
- 受験科目: 通常レート
- 非受験科目・読書・その他: **1日100 BPまで**(受験勉強を押しのけないための上限)

### 生活習慣(本人が任意でON。デフォルトOFF)

| 習慣 | BP |
|---|---|
| 24時前に就寝 | +20 |
| 朝ごはんを食べた | +15 |
| 運動30分 | +30 |
| 休憩をちゃんと取った | +10 |
| 読書30分 | +40 |

→ **コンディションメーター**に蓄積。**翌日の倍率が +0.05〜+0.3**。
「ダンサーは体が資本」という世界観に合致させる。

## C. 時事ニュース学習

**アプリはニュースを取得しない。** 本人が新聞・NHK・スマホで読み、
**見出しと自分の一言だけ**をアプリに記録する(記事本文は保存しない=著作権対応)。
深掘りは既存の「🤖 AIに聞く」機能が担う。

| 入力 | 例 |
|---|---|
| ジャンル | 経済 |
| 見出し(自分の言葉で) | 円安が1ドル160円台に |
| 一言(なぜ気になったか) | 輸入品が高くなる理由が分かった気がする |

保存後に **「このニュースをAIに聞く」ボタン**が出る。志望学部に応じて質問文が自動生成される:

次のニュースについて、①背景を中学生にも分かるように、

※②の部分は志望学部により自動で切り替わる(法学部なら法的論点、国際学部なら他国の対応)

## D. 金融シミュレーション

### 通貨は3つ

| 通貨 | 性質 | 稼ぎ方 | 使い道 | 為替 | 金利 |
|---|---|---|---|---|---|
| **BP** ビートポイント | ゲーム内の**円** | 学習・ニュース・生活習慣 | 国内ショップ、円預金 | — | ○(低い) |
| **BD** ビートドル | ゲーム内の**外貨** | BPから**両替** | 海外ショップ、外貨預金 | ○ | ○(高い) |
| **GT** ゴールドチケット | **現実のお金の引換券** | マイルストーンのみ | PayPay交換 | ○(交換時) | — |

### 金利 — 「アプリの1週間 = 現実の1年」(52倍速)

現実の金利(年0.2%等)は低すぎて体感できないため、時間軸を圧縮する。
**画面に必ず次を明記すること:**

> 💡 現実の金利は「1年でこれだけ」。このアプリでは体感できるよう
> **1週間でその分**つくようにしています(52倍速)

| 預け先 | 参考金利 | ロック期間 | 途中解約 |
|---|---|---|---|
| 普通預金(BP) | 年0.2% | なし・いつでも出せる | — |
| 定期預金1ヶ月(BP) | 年0.35% | 4週間 | 利息なし |
| 定期預金3ヶ月(BP) | 年0.5% | 12週間 | 利息なし |
| **外貨預金(BD)** | **年4.5%** | なし | **為替リスクあり** |

※金利は**本人が実際の数値を調べて入力**する(E章)

### 【最重要】外貨預金の結果表示

「金利が高くても為替で負ける」を体験させることが、この機能の最大の目的。
**必ず内訳を分解して見せること。**

```
預入時   : 10,000 BP → 66.7 BD（1BD = 150円）
1週間後  : 利息 +3.0 BD → 69.7 BD（年利4.5%）
         : 為替が 1BD = 140円 に（円高）
円換算   : 69.7 BD × 140円 = 9,758 BP

  利息で増えた分      : +450 BP
  為替で目減りした分  : -692 BP
  ──────────────────────────
  結果                : -242 BP  😨
```

### 為替とショップ

| ショップ | 通貨 | 価格 | 円換算 |
|---|---|---|---|
| 🇯🇵 国内ショップ | BP | **固定** | 変わらない |
| 🌍 海外ショップ | BD | **固定** | **為替で変動** |

**同じアイテムを両方に置く**こと。円高のとき海外ショップが安くなる体験が学びになる。

| アイテム | 国内 | 海外 | 1BD=150円 | 1BD=130円 |
|---|---|---|---|---|
| フェドーラハット | 3,000 BP | 20 BD | 3,000 BP(海外は高い) | **2,600 BP(海外が得!)** |

海外ショップ限定アイテム(「ロサンゼルス限定スニーカー」等)を置くと、
「いつ買うか」を考えるようになる。

### PayPay交換 — 予算の安全性

> **月間上限は「円建て」で固定。為替が動かすのは「上限に届くまでに必要なGTの枚数」**

| 状況 | 1GTの価値 | 2,000円分に必要なGT | 本人から見ると |
|---|---|---|---|
| 基準(1ドル150円) | 100円 | 20枚 | 標準 |
| **円安**(1ドル165円) | **110円** | **18枚** | 少ない枚数で満額 = **お得** |
| **円高**(1ドル135円) | **90円** | **23枚** | 多く必要 = **損** |

- 親の支出は月額固定(例 2,000円)。**為替がどう動いても1円も超えない**(変動幅±20%でキャップ)
- 「今は円高だから来月まで待とう」という判断が生まれる ← **この"待つ"判断が最大の学び**
- 上限は毎月リセット。**繰り越さない**

**PayPayへの入金は自動化できない**(個人アプリ向けの公開APIが存在しないため)。
アプリは「交換申請の内容を表示・共有」までを担い、**親が手動でPayPay送金**する。
アプリ側で「支払済み」にする操作が必要。

| 条件 | GT |
|---|---|
| 週の学習目標を達成 | 1 GT |
| 月の学習目標を達成 | 3 GT |
| 単元を完全制覇 | 2 GT |
| 模試で前回より点数UP | 5 GT |
| 全受験科目を1ヶ月継続 | 5 GT |
| 志望校の判定がUP | 10 GT |
| 週末のまとめを提出 | 1 GT |
| 週末のまとめ4週連続 | 3 GT |

### 分割払い — 必ず総額を並記すること

```
🎤 ワールドステージ

  一括払い    50,000 BP
  3回払い     52,500 BP  (+2,500 BP)   1回 17,500 BP
  6回払い     55,000 BP  (+5,000 BP)   1回  9,167 BP
  12回払い    59,000 BP  (+9,000 BP)   1回  4,917 BP
                ↑
      分割にすると 9,000 BP 多く払うことになるよ
```

**この比較画面を毎回見せること自体が教育。** 借金を推奨する設計にしない。

### 信用スコア

| 出来事 | スコア |
|---|---|
| 初期値 | 500点 |
| 返済を1回完了 | +50 |
| 完済 | +100 |
| **返済日に残高不足(延滞)** | **−150** |

| スコア | 効果 |
|---|---|
| 700点以上 | 分割手数料が**半額**、借入上限アップ |
| 500〜699点 | 標準 |
| 300点未満 | **分割払いが使えなくなる** |

### 段階解放(いきなり全部出さない)

| Lv | 解禁条件 | 解禁される機能 | 学ぶこと |
|---|---|---|---|
| 1 | 最初から | BPを貯める・使う | お金の基本 |
| 2 | 5,000 BP 到達 | 円普通預金・利息 | 金利、複利 |
| 3 | **定期預金を1回満期まで持つ** | 定期預金 | 流動性 vs リターン |
| 4 | 経済ニュースを10本記録 | 両替・外貨預金・海外ショップ | 為替、内外価格差 |
| 5 | 外貨で為替差損益を1回経験 | PayPay交換の為替連動 | 実生活への接続 |
| 6 | 20,000 BP 到達 | 分割払い・信用スコア | 借入コスト、信用 |

Lv.3の条件は意図的。**「一度我慢して満期まで持つ」経験をしないと次に進めない。**

## E. 週次マーケット入力

毎週日曜に、本人が実際の数値を調べて入力する(**自動取得はしない**)。
**調べる行為自体が学習**であり、外部通信ゼロの設計とも合致する。

```
📊 週次マーケット入力（毎週日曜）

  ドル円レート      [ 152.30 ] 円
  日経平均          [ 41,250 ] 円
  普通預金金利      [   0.20 ] %
  米ドル預金金利    [   4.50 ] %

  なぜ動いた? [ 日銀が利上げを見送ったから円安が進んだ    ]

  → 保存するとアプリ内の為替・金利がこの数値に更新されます
```

- 既存のSVGグラフ描画を流用し、推移を折れ線で表示
- 各点に**自分のメモ**が紐づく → **自分だけの経済年表**ができる
- 入力後に「🤖 AIに聞く」で数字の意味を解説してもらえる

## 安全装置(必ず実装すること)

1. **投機ゲーム化の防止**: 両替は**週1回まで**。マーケット入力は日曜のみ。デイトレードにしない
2. **受験直前の集中モード**: **受験日の30日前**になったら金融・ショップ機能を**自動でOFF**にし、
   シンプルな学習記録とカウントダウンだけに戻す
3. **BP獲得の1日上限 1,500 BP**
4. **非受験科目・読書は1日100 BPまで**
5. **PayPay月間上限は円建てで固定**(為替が動いても親の支出は不変)
6. **生活習慣・金融機能は本人が任意でON**(押し付けない)
