## 2. 作るもの —— 26枚

**1つの画角で会話も全身の動作もまかなうことはできない。**
全身の引きだと顔が画面の数%しかなく、口を動かしても見えない。
かといってバストアップだけでは、挨拶もお辞儀も表現できない。だから**2種類**作る。

### 2.1 会話用バストアップ(18枚)

会話中はずっとこの画角。口の動きが見える大きさが要る。

| 画角 | 胸の上端から頭頂まで。**顔が画面の高さのおよそ40%**。正面向き、カメラ目線 |
|---|---|
| 寸法 | **1024 × 1024**(正方形) |
| 枚数 | 6表情 × 口3段階 = **18枚** |
| ファイル名 | `talk_<感情>_<口>.png` |

| 感情 | 表情の指示 |
|---|---|
| `neutral` | 中立。口角はわずかに上がる程度。眉はまっすぐ。**基準画像の表情そのもの** |
| `joy` | 喜び。目を細めて頬を上げ、口角をはっきり上げる。眉はやや上がる |
| `anger` | 怒り。眉を内側に寄せて下げ、目に力を入れる。**怖い顔にしない。少し拗ねた程度に留める** |
| `sad` | 哀しみ。眉の内側を上げて下がり眉に。目線をわずかに落とし、口角を下げる |
| `fun` | 楽しさ。歯を見せてにっと笑う。眉を上げ、目を輝かせる |
| `surprise` | 驚き。目を大きく見開き、眉を高く上げる。あごをわずかに引く |

| 口 | 指示 |
|---|---|
| `closed` | 完全に閉じている |
| `half` | 少しだけ開ける(母音の「イ」か「ウ」の程度)。歯はほとんど見えない |
| `open` | 大きく開ける(母音の「ア」)。**口の形以外は一切変えない**。目も眉も顔の向きもそのまま |

> ### ⚠ 会話用でいちばん重要な条件
>
> **18枚すべてで、顔の位置と大きさを完全に揃えること。**
> あとでプログラムが「口を閉じた絵」と「開いた絵」の**差分**を取って口レイヤーを作る。
> 顔が少しでもずれていると、差分が顔全体に広がって使えない。
>
> 同じ感情の3枚(`closed` / `half` / `open`)は、**口以外まったく同じに見えること**。

### 2.2 全身の動作(8枚)

数秒だけ表示して会話画面へ戻る演出用。顔が小さいので口は動かさない。

| 画角 | 全身。頭上と足元に少し余白。**基準画像と同じ引き** |
|---|---|
| 寸法 | **768 × 1024**(縦長) |
| 枚数 | **8枚** |
| ファイル名 | `pose_<動作>.png` |

| 動作 | 指示 |
|---|---|
| `idle` | **基準画像とまったく同じ立ち姿。**左手を腰に、右手でバッグ。標準の姿 |
| `greet` | 右手を顔の横まで上げ、手のひらを開いて軽く振る。バッグは左手へ持ち替え。笑顔 |
| `nod` | うなずいた瞬間。あごを軽く引き、頭をわずかに前へ。立ち位置は変えない |
| `think` | 右手の指を軽くあごに添え、視線をやや上に外す |
| `cheer` | 両手を胸の高さで軽く握り、肩を上げて喜ぶ。バッグは足元に置く。満面の笑み |
| `point` | 右手で前方斜め下を指し示す。視線は指の先へ |
| `surprise` | 右手の指先を口元に添え、目を見開く。上体をわずかに引く |
| `bow` | 腰から浅く前傾して会釈。両手を前で軽く重ねる。目線は下 |

> **全身で揃えること**: 立ち位置と身長の見え方を8枚で統一する。
> 服装とアクセサリーは基準画像と一致させる。

## 3. 毎回のプロンプトの組み立て方

**4つを必ずこの順で連結する。** 1つでも欠けるとぶれる。

```
① 画風        style(実写風・カメラ・光・背景・禁止事項)
② 一貫性の指示 consistency(同じ人物・同じ構図・変えてよい部分の明示)
③ 画角        views.talk.framing または views.pose.framing
④ 中身        emotions[…] + mouths[…]   /   poses[…]
```

すべて `avatar_face_prompts.json` に入っている。`tools/gen_face_assets.py` が
この順で組み立て、**基準画像を先に、文章を後に**渡す。
参照画像を先に置くと、モデルが「これを直す」と解釈しやすい。

### 共通の禁止事項(全26枚)

- 文字・ロゴ・透かし・フレームを入れない
- **通行人を入れない**(切り抜きの邪魔になる。基準画像には写っているが、生成分では消す)
- 顔の造作(目の形・鼻・輪郭・髪型)を変えない
- 服装とアクセサリーを変えない
- イラスト調・CG調にしない。**基準画像と同じ写実性**を保つ

## 4. 受け入れ条件 —— これを満たさない画像は使わない

目で確かめる。自動検査では絵の良し悪しは分からない。

### 会話用18枚

- [ ] 18枚すべてで顔の位置と大きさが揃っている(重ねてもずれない)
- [ ] 同じ表情の3枚は、口以外がまったく同じに見える
- [ ] 髪型・服・アクセサリーが基準画像と一致している
- [ ] 通行人が写り込んでいない
- [ ] `anger` が怖い顔になっていない

### 全身8枚

- [ ] 8枚すべてで同じ人物に見える
- [ ] 立ち位置と身長の見え方が揃っている
- [ ] 服装が基準画像と一致している
- [ ] **手や指が破綻していない(指の本数を必ず数える)**

## 5. 出来た画像をどうするか

```bash
# ① 会話用18枚から「口レイヤー」を作る(全身は不要)
for e in neutral joy anger sad fun surprise; do
  python tools/split_mouth.py raw/talk_${e}_closed.png raw/talk_${e}_half.png \
      raw/talk_${e}_open.png --out assets/characters/ibuki_navi --emotion talk_${e}
done

# ② 全身8枚はそのまま置く
cp raw/pose_*.png assets/characters/ibuki_navi/

# ③ マニフェストと SHA-256 一覧を作る
python tools/build_manifest.py assets/characters/ibuki_navi

# ④ 突き合わせ検査
python tools/check_assets.py assets/characters/ibuki_navi/manifest.json --require-all
# → OK: 会話用 6 表情 / 全身 8 動作、すべて描ける

# ⑤ 見た目の確認(APIに繋がない)
python -m avatar_talk --demo
```

**口レイヤーの作り方**: `split_mouth.py` は「口を閉じた絵」と「開けた絵」の
**違う画素だけ**を残した透過 PNG を作る。生成モデルに透過画像を作らせるより確実で、
位置合わせも要らない。詳しくは `AVATAR_TALK_DESIGN.md` 5.2 節。

## 6. 権利と来歴

- 26枚は**生成 AI による作成物**。`assets/items/MANIFEST.md` と同じ方針で、
  **権利関係の判断は親(arumat-ken)が行う**
- `MANIFEST.md` は自動生成物なので、**出所と利用許諾を推測で書かない**。
  人が `SOURCES.md` に書き残す
- 基準画像に写り込んでいる通行人は、生成分では除く

## 7. Codex(ChatGPT)への依頼

`docs/exchange/PROTOCOL.md` の役割分担では、**見た目の判断は Codex** の担当。

| 依頼したいこと | 具体的に |
|---|---|
| プロンプト文の推敲 | `avatar_face_prompts.json` の `emotions` と `poses` の日本語。**表情の指示が具体的すぎても抽象的すぎても破綻する**。生成結果を見ながら詰めてほしい |
| 受け入れ判定 | 4節のチェックリストで26枚を見る。特に**顔の位置ずれ**と**指の破綻** |
| 動作8種の妥当性 | 会話に本当に要る動作か。足りない/多すぎるものはないか |
| 表情6種の妥当性 | 高校生の勉強の相棒として、`anger` は要るか。別の表情に置き換えるべきか |

Codex は `codex/*` ブランチで `docs/` 配下のみを変更する(PROTOCOL.md 境界1)。
`avatar_face_prompts.json` は `docs/design/` の中なので、**Codex が直接直してよい**。
