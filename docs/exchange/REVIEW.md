## D.【要確認】設計判断として再検討したい点

### D-1【重要】集中モードで「コーチ」タブごと非表示にする件

設計書 §6 は、集中モード中に **世界・コーチの両タブを非表示**にするとしている。
しかし**コーチ画面には既存 ver.3.3.0 の機能が含まれている**。

| コーチ画面の機能 | 種別 | 集中モードで消えてよいか |
|---|---|---|
| 装備・ショップ | ver.4 新規 | ✅ 消してよい(設計意図どおり) |
| 仲間コレクション | ver.4 新規 | ✅ 消してよい |
| ポーズ変更 | **既存 ver.3.3.0** | 判断が必要 |
| メッセージ(端末内コーチ) | **既存 ver.3.3.0** | 判断が必要 |
| **🤖 AIに聞く** | **既存 ver.3.3.0** | ❌ **消すべきでない** |

親の当初要望は「**金融・ショップ機能**が自動でOFF」であり、コーチ画面全体の非表示ではない。
特に「AIに聞く」は、**受験直前こそ小論文・面接の相談に使いたい機能**である。

**Claudeの提案**: 集中モードでも**コーチタブは残し、その中の装備・ショップ・仲間カードだけを隠す**。
タブは 今日／記録／グラフ／**コーチ**／設定 の5タブとする。
(この判断は親の承認が必要)

### D-2 記録画面への「科目フィルタ」の追加

設計書 §2.2 のワイヤーに `[科目フィルタ]` があるが、これは**現行 ver.3.3.0 に存在しない新機能**。
依頼書では「仕様にない機能を勝手に追加しない。追加提案は【提案】と明示して分離する」と指示していた。

機能自体は有用なので、**【提案】として明示した上で採用可否を判断**したい。
