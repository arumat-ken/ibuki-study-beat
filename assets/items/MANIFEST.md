# アイテム画像マニフェスト (APP-430)

このフォルダの画像は、ショップと装備欄でアイテムの見た目を示すために使う。
**すべてリポジトリ内から参照し、外部URLへは一切アクセスしない。**

## 記録の方針

このマニフェストには、**ファイルから確認できる事実だけ**を書く。
確認できないものは推測で埋めず「**未記録**」とする。

- **出所**: どの生成手段で作られたかは、画像ファイル自体からは判別できない。
  制作の経緯として Draw Things(ローカル生成)と Gemini(生成)の両方が使われたことは
  分かっているが、**どのファイルがどちらかを特定できないため「未記録」**とする。
- **利用許諾**: 生成AIによる作成物である。**権利関係の判断は親が行う。**
  ここでは推測による断定をしない。

## 表示のきまり

- 画像は静止画のみ。動きは付けない。
- **画像が読み込めなくても、名称・効果・価格・購入・装備の操作は変わらず使える。**
  `onerror` で枠ごと隠し、文字だけが残る。
- `sw.js` の `ASSETS` に15点すべてを載せているので、オフラインでも表示される。
- ショップは48×48、装備欄は34×34で表示する。元画像は512×512。

## 対応の確認

アイテムIDとファイル名は1対1で一致する。次で確認できる。

```bash
node -e "
const C=require('./js/calc.js');
const ids=[...C.COSTUME_ITEMS,...C.SKILL_ITEMS,...C.STAGE_ITEMS].map(i=>i.id);
const files=require('fs').readdirSync('assets/items').filter(f=>f.endsWith('.png')).map(f=>f.slice(0,-4));
console.log('欠け:', ids.filter(i=>!files.includes(i)), '余り:', files.filter(f=>!ids.includes(f)));
"
```
