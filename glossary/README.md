# 用語集アプリ (glossary/)

`docs/GLOSSARY.md` を、iPhoneのホーム画面から開いて検索できるようにしたものです。

公開URL: `https://arumat-ken.github.io/ibuki-study-beat/glossary/`

## 仕組み

- `docs/GLOSSARY.md` を**実行時に読み込んで**表示します。用語集の原文はこれまでどおり
  Markdown 1枚で、Codexが追記すれば次に開いたときに反映されます。
  **このフォルダのHTMLを編集する必要はありません。**
- `##` を分類、`###` を1語のカードとして並べます。`###` を持たない `##`（表だけの節）は、
  その節ごと1枚のカードになります。
- 検索は見出しと本文の部分一致で、一致箇所を強調します。
- Service Worker は `glossary/` 配下だけを対象にしており、アプリ本体の `sw.js` とは
  干渉しません。原文はネットワーク優先・キャッシュ予備なので、オフラインでも最後に
  読んだ内容が開きます。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・簡易Markdown描画・検索（外部ライブラリなし） |
| `manifest.webmanifest` | ホーム画面追加時の名前とアイコン |
| `sw.js` | オフライン用キャッシュ。シェルを変えたら `CACHE` を上げる |
| `icons/` | ホーム画面アイコン（本体アプリとは別の絵柄） |

## iPhoneのホーム画面に置く

1. Safariで公開URLを開く
2. 下部の共有ボタン → **ホーム画面に追加**
3. 名前は「用語集」のまま **追加**

## 動作確認

リポジトリ直下で静的サーバを立て、`/glossary/` を開きます。

```
python3 -m http.server 8791
```

受け入れ試験（26項目・iPhone 13相当の画面幅、オフライン復帰を含む）は
`tests/e2e/glossary.mjs` にあります。
